## What This System Does

The notebook implements a **cryptocurrency trading agent backtester** that:

1. **Analyzes** historical price data (7-day windows)
2. **Predicts** price movements using AI agent (gpt-5-mini)
3. **Reviews** predictions against actual outcomes (next 7 days)
4. **Scores** accuracy using another AI agent
5. **Tracks** costs throughout the process
6. **Repeats** across ~48 overlapping time windows for statistical significance

## Quick Architecture

```
MySQL Database (4H klines)
    ↓
Data Fetching (7 days analysis + 7 days review)
    ↓
[Batch API - Phase 1]
  ├─ Technical Analysis Agent generates predictions
  └─ Results saved
    ↓
[Batch API - Phase 2]
  ├─ Reviewer Agent evaluates predictions vs actuals
  └─ Results saved
    ↓
Final Report (backtest_report.json)
  ├─ Predictions
  ├─ Reviews
  ├─ Accuracy scores
  ├─ Token counts
  └─ Cost tracking
```

## Core Agents

### 1. Technical Analysis Agent
- **Role**: Analyzes historical price data
- **Input**: 7 days of 4H candlestick data
- **Output**: Price predictions, support/resistance levels, entry/exit signals
- **Model**: gpt-5-mini

### 2. Reviewer Agent
- **Role**: Evaluates prediction accuracy
- **Input**: Agent's prediction + actual outcome
- **Output**: Accuracy score, feedback, improvements
- **Model**: gpt-5-mini

### 3. Trading Agent
- **Role**: Makes trading recommendations
- **Input**: Market data, technical analysis
- **Output**: Trading signals, position sizing
- **Model**: gpt-5-mini

## Two Execution Modes

### Mode 1: Batch API (Recommended for Large Scale)
- Asynchronous processing
- Cost-effective for many windows
- 5-30 minutes per phase
- Better for production

### Mode 2: Direct Execution (Good for Testing)
- Real-time feedback
- Single or multiple windows
- Supports parallel execution
- Better for validation

## Workflow Steps

### Phase 1: Technical Analysis
1. Generate batch requests (JSONL)
2. Preview for safety
3. Submit to OpenAI
4. Monitor status
5. Download results
6. Process and save

### Phase 2: Review Evaluation
1. Generate review batch from Phase 1 results
2. Submit to OpenAI
3. Download results
4. Combine with Phase 1
5. Generate final report

## Key Features

1. **Two-Phase Architecture**
   - Separates analysis generation from evaluation
   - Better error handling
   - Allows parallel processing

2. **Sliding Windows**
   - Overlapping time periods (11-day overlap)
   - Maximizes data usage
   - Increases statistical significance

3. **Cost Tracking**
   - Estimates before running
   - Tracks actual usage
   - Prevents budget surprises

4. **Error Recovery**
   - Partial results extraction
   - Retry mechanisms
   - Progressive saving

5. **Metadata Correlation**
   - Maps requests to windows
   - Enables result reconstruction
   - Supports partial recovery
